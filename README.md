# РЕШАЙ360 — концепт сайта

Отдельный демонстрационный прототип новой главной страницы РЕШАЙ360.

## Что внутри

- Адаптивная одностраничная главная страница для компьютеров и мобильных устройств.
- Позиционирование: «Знания, которые можно измерить».
- Первый экран с выгодой для пользователя и визуальным примером отчёта.
- Блоки результата диагностики, сравнения динамики, сценариев использования и процесса.
- Интерактивный выбор класса (7–11) и уровня диагностики.
- Демонстрационные цифры и цены — не являются подтверждённым коммерческим предложением.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория (Settings → Pages → Deploy from a branch → main → /(root)).

## Важно

Это только концепт интерфейса. Реальная диагностика, авторизация, оплата, генерация PDF и обработка данных не подключены. Выбор класса и уровня работает локально в браузере и не создаёт заказов. Действующий сайт и его репозиторий не затрагиваются.
