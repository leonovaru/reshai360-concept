# РЕШАЙ360 — диагностическая платформа

Демонстрационный прототип независимой диагностики знаний по математике для 7–11 классов.

## Что уже перенесено

- 10 диагностик: 7–11 классы, базовый и продвинутый уровни.
- Банк заданий и тематическая структура из исходного проекта.
- Правила проверки ответов, навигация по заданиям, отметки для возврата и локальное сохранение прогресса.
- Формирование результата и PDF-отчёта в браузере.
- Тематические программы классов и связки в `data/config.js`.
- Главная страница с выбором класса/уровня и раскрывающейся программой.

## Запуск

Проект — статический сайт. Для локального просмотра откройте `index.html` через локальный сервер или опубликуйте репозиторий через GitHub Pages.

Диагностики находятся в `diagnostics/`.

## Важное ограничение текущей версии

Это демонстрационный прототип на GitHub Pages. Проверка платного доступа, ЮKassa, выдача токенов, серверное сохранение результатов, отправка PDF на email/Telegram и промокоды не перенесены. В демо тесты открываются без оплаты, прогресс сохраняется локально в браузере, PDF формируется на устройстве.

Для запуска коммерческой версии потребуется отдельный backend и защищённое подключение платёжного провайдера. Секретные ключи и токены нельзя размещать в публичном репозитории.
